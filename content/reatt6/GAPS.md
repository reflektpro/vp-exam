# Переаттестации v2 — чего не хватает и конфликты в документах

Вопросы на спорные места не создавались (или исключены). Список для решения руководством.

## Не хватает документов / пунктов

- **УПК РФ** не входит в перечень документов переаттестаций по ТЗ (ТК, ФЗ, ФКЗ, КоАП, ДУ, КПС, СУ, ВУ, УК, ПК) — 3 вопроса банка курса ПК (ссылки на УПК) в базы не взяты. Если УПК нужен — добавить в перечень.
- **ФЗ / ФКЗ «важнейшие для службы»** — в проекте нет документа, который определяет, какие именно положения считаются важнейшими для Средней; отбор для Средней сделан по сложности (лёгкие/средние) из ПК, КоАП, 6 ФЗ и ФКЗ об особых правовых режимах. Нужен перечень, если отбор должен быть иным.
- **Изображения (фото, скриншоты)** — в загруженных материалах нет фотографий/схем. Сделана одна SVG-схема (двухшереножный строй) строго по определениям СУ пп. 6–15.1; остальные задания с картинками администратор может добавить загрузкой изображений в админке.
- **Внутренние кейсы** — в документах есть материал только для 32 кейсов (по 8 на ВУ, ДУ, КПС, СУ); база = 4 попытки по 8 кейсов. Для большей базы нужны дополнительные утверждённые ситуации.
- **Сложность внутренних кейсов** в исходных материалах не указана — назначена по числу пунктов устава в эталонном ответе (≤2 — лёгкий, 3–4 — средний, ≥5 — сложный); администратор может изменить.

## Конфликты в документах

- **ВУ п. 2.8 ↔ ВУ п. 6.57 «б»**: кто восстанавливает в воинских званиях — Батальон ВП или Отдел призыва. Вопросы не задаются.

Вопросы на эти ссылки и литеры не задаются.
